# رحلة علم البيانات والذكاء الاصطناعي: موقع تفاعلي ثلاثي الأبعاد

موقع ثابت (بدون Build) يُنشر على **GitHub Pages**، وقاعدة بياناته **Supabase**.

| الصفحة | الرابط | الاستخدام |
|---|---|---|
| تطبيق الطلبة (هاتف) | `index.html` | ينضم الطالب باسمه وفريقه (شباب/بنات) ويجيب ويصوّت ويسأل |
| شاشة المقدّم | `present.html` | العرض الرئيسي على البروجكتر + التحكم المباشر بالمسابقات |

## 1) جرّب فورًا بدون أي إعداد (الوضع التجريبي)
افتح الموقع من أي خادم محلي (`python3 -m http.server`) ثم:
- المقدّم: `present.html?demo=1` (كلمة المرور `demo`)
- الطلبة (تبويبات أخرى بنفس المتصفح): `index.html?demo=1`  (لتجربة أكثر من طالب: أضف `&dev=a1` ثم `&dev=b2`…)

## 2) الإعداد الحقيقي مع Supabase (10 دقائق)
1. أنشئ مشروعًا في https://supabase.com
2. من **SQL Editor** شغّل بالترتيب: `supabase/schema.sql` ثم `supabase/seed.sql`.
3. **Authentication → Users → Add user**: أنشئ حساب المقدّم (بريد + كلمة مرور، فعّل Auto Confirm).
4. في SQL Editor أضفه مقدّمًا:
   ```sql
   insert into admins(user_id) select id from auth.users where email = 'بريدك@example.com';
   ```
5. **Authentication → Providers → Email → عطّل Allow new users to sign up** (مهم: حتى لا يصير أحد مقدّمًا).
6. **Project Settings → API**: انسخ `Project URL` و `anon public key` إلى `js/config.js`:
   ```js
   SUPABASE_URL: 'https://xxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJ...',
   ```
   (مفتاح anon عام بطبيعته؛ كل الكتابة تمر عبر دوال RPC محمية، والتصحيح يتم في الخادم فلا يمكن للطالب كشف الإجابات أو تزوير نقاطه.)
7. **Database → Replication**: تأكد أن الجدول `session_state` ضمن Realtime (يفعّله schema.sql تلقائيًا). الموقع يعمل أيضًا بالاستطلاع كل 3 ثوانٍ إن تعطّل Realtime.
8. كلمة السر الختامية (لإنهاء الرحلة +20 XP): الافتراضية `DATA2026`، غيّرها بـ:
   ```sql
   update sessions set secret_code = 'كلمتك' where id = 'main';
   ```

## 3) النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع (الملف `.nojekyll` موجود).
2. **Settings → Pages → Deploy from a branch → main / (root)**.
3. الرابط: `https://USERNAME.github.io/REPO/` ؛ المقدّم: `.../present.html`.
جميع المسارات نسبية فتعمل داخل مجلد المستودع. باركود الانضمام يُولَّد تلقائيًا من رابط الموقع.

## 4) يوم اللقاء
1. قبلها بيوم: افتح `present.html` → ⋯ → **تصفير الجلسة** (يحذف تجارب التدرّب).
2. اعرض `present.html` على البروجكتر (F = ملء الشاشة). مشهد «الشباب ضد البنات» يعرض باركود الانضمام.
3. اختصارات: `Space` الإجراء التالي (فتح السؤال ← إغلاق ← كشف الإجابة ← التالي) · `→`/`PageDown` التالي · `←` السابق · `G` فهرس المشاهد · `Q` باركود كبير · `F` ملء الشاشة · `1–4` سنوات الخطة.
4. في مشهد «مجرة الوظائف» اضغط كوكبًا لعرض الوظيفة (والطلبة يرون المجرة على هواتفهم أيضًا).
5. مشهد «الأسئلة» يعرض أسئلة الطلبة مرتبة بالتصويت، ويمكنك وسمها «تمت» أو إخفاؤها.
6. في الختام تظهر كلمة السر من ⋯ → «إظهار كلمة السر» فيدخلها الطلبة ويقيّمون اللقاء.

## نظام النقاط
- إجابة صحيحة 10 نقاط + حتى 5 نقاط سرعة · فكرة +10 · تصويت +2 · سؤال +5 (أول 3) · تقييم +10 · كلمة السر +20.
- ترتيب الفريقين = **متوسط نقاط اللاعب النشط** (عادل إن اختلف العدد). لتغييره إلى المجموع: `TEAM_SCORING: 'total'` في `config.js`.
- 5 مستويات و10 شارات وسلاسل إجابات متتالية وتفاعلات إيموجي مباشرة.

## ملاحظات
- المحتوى كله في `js/content.js` (الأسئلة، الوظائف، المشاهد). بعد تعديل الأسئلة أعد توليد `seed.sql` بتشغيل `cd tools && node gen_seed.mjs` (أو عدّلها يدويًا).
- يتطلب متصفحًا يدعم WebGL؛ وفي الأجهزة الضعيفة يخفّف الموقع المؤثرات تلقائيًا ويحترم إعداد «تقليل الحركة».
- راجع قبل اللقاء الأرقام الحساسة: تفاصيل غينيس، وأرقام Gaza Stars (2000+ متقدم / 150 فكرة).
